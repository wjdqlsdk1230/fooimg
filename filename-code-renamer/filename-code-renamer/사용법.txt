[작동 방식]

기본.png    -> 번호 변환 후\01.png
미소.webp   -> 번호 변환 후\02.webp
전투준비.jpg -> 번호 변환 후\43.jpg

[사용 방법]

1. 파일명_번호변환.cmd 파일을 이미지가 있는 폴더에 복사합니다.
2. 이미지 파일명을 코드표의 한글 이름과 정확히 같게 맞춥니다.
3. 파일명_번호변환.cmd를 더블클릭합니다.
4. 자동으로 생성된 "번호 변환 후" 폴더에서 결과를 확인합니다.
5. 01~109 중 없는 항목이 있으면 작업 종료 전에 번호와 이름이 표시됩니다.

[특징]

- 결과 파일명은 01부터 109까지의 번호만 사용합니다.
- 확장자는 원본 그대로 유지합니다.
- 원본 파일은 수정하거나 삭제하지 않습니다.
- 기존 결과 파일과 이름이 같으면 새 복사본으로 덮어씁니다.
- Python이나 ExifTool을 설치할 필요가 없습니다.
- PNG, JPG, JPEG, WEBP, BMP, TIF, TIFF, GIF, AVIF, JXL을 지원합니다.
- 한글 이름이 정확히 일치하지 않는 파일은 건너뜁니다.
- 빠진 항목은 "번호 변환 후\누락 목록.txt"에도 저장됩니다.
- 모든 항목이 있으면 "01부터 109까지 빠진 번호가 없습니다"라고 표시됩니다.
